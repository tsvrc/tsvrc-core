# TsVRC

Open-source UdonSharp framework for VRChat worlds: structured initialization, dependency
wiring, and editor codegen.

Docs: [tsvrc.com](https://tsvrc.com) · Not affiliated with, endorsed by, or sponsored by
VRChat Inc.

## Install

See [Add TsVRC to your project](https://tsvrc.com/docs/tsvrc/add-to-your-project) for
VCC and `.unitypackage` install steps.
